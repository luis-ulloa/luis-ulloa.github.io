WC 2026 Summary

Synopsis: Do you enjoy real football, or fútbol, a.k.a. soccer? If you do, you know the top event is the quadrennial international tournament that brings together national teams from all over the world. For six weeks in summer 2026, this tournament was held in North America, across all three constituent countries: Canada, the United States, and Mexico. Being the analytical nerd that I am, I manually scraped the data for each match after each game’s completion and organized it across different tables. Once the tournament ended, I used SQLite to do some initial analysis. Most insights from that analysis can be found in my GitHub account. However, in order to also showcase my advanced Excel skills, I built a one-page dashboard that summarizes the tournament at the match level and by stage. The data behind it is the main table that other tables would connect to in a SQL environment. To download the workbook and embedded dashboard, click here.

Competencies: Excel, pivot tables, pivot charts, slicers and report connections, interactive dashboard design and development, calculated fields, dynamic formulas and KPI cards

Link to project repo: GitHub

TheLook E-Commerce

Synopsis: Any person who works with data is familiar with Google BigQuery. That’s one of the tools I use to practice my SQL skills, so I won’t forget it or get rusty (use it or lose it). One of the public datasets available for practice is TheLook eCommerce, which is a fictional dataset meant to mimic an e-commerce operation. As part of my SQL practice, I prompted Claude to come up with a list of increasingly challenging business inquiries, which I then answered by building the corresponding queries. It’s a smart use of AI to advance one’s skills. The queries I built are available in my GitHub account. Towards the end of that exercise, I ended up creating four customized datasets with certain levels of aggregations and insights that piqued my interest. I took one of those customized datasets to practice my Tableau skills and build a simple e-commerce dashboard, where I can see a quick summary of KPIs by country, sales year and product. To go directly to that dashboard on Tableau Public, click here.

Competencies: Tableau, interactive dashboard development, data visualization, geospatial analytics, KPI cards, time-series analysis, and business intelligence

Link to project repo: GitHub

Housing Price Prediction

Synopsis: In the United States people value spacious properties. Therefore, it is assumed that the more living space is available in a house, and the bigger the lot, the higher the price the property would command in the local market. This analysis aims to build a predictive pricing model based on that premise. The model will utilize multiple linear regression techniques, and the model's performance will be assessed using the metric Root Mean Squared Error (RMSE). Once the model is built and refined, it will be used to predict sales prices as part of an internal Kaggle challenge.

Competencies: Python, EDA, Statistical Analysis, Feature Engineering, Regression Modeling, Predictive Analytics, and Model Evaluation

Link to project repo: GitHub

Ride BigApple

Synopsis: Can yellow cab fares be predicted within New York City's five boroughs based on time of the day, time of the year and certain high passenger areas? The aim here is to use existing historical data of NYC cab rides spanning several years and building a model that can be integrated into a simple app to request a taxi ride and predict the expected fare and distance for the passenger.

Competencies: Python, Data Cleaning, EDA, Geospatial Analytics, DBSCAN Clustering, Feature Engineering, Predictive Modeling, Model Evaluation and Streamlit
